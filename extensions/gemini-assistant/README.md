# Gemini Code Assistant

This folder contains a `Gemini`-inspired coding assistant extension for VS Code.

Features:
- Free and independent from GitHub Copilot
- Good C/C++ support
- Local file upload from the device
- Inline suggestion generation
- A polished panel with a premium dark theme
- Stronger than a default completion box

## Commands
- `Gemini: Open Assistant Panel`
- `Gemini: Upload Local Files`
- `Gemini: Generate Suggestion from Prompt`

## Suggested usage
1. Open VS Code with this repo.
2. Run the extension from the Extension host.
3. Open a `.c`, `.cpp`, `.ts`, or `.js` file.
4. Use the panel or inline suggestions.

This is designed as a local, offline AI-style helper while avoiding a paid external dependency.

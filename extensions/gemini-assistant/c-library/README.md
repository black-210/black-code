# Gemini Advanced C Toolkit

This directory contains stronger C utilities and examples designed for more practical, production-like coding workflows.

## Included modules
- `dynamic_array` — dynamic array abstraction with push/insert/remove operations
- `linked_list` — a fast singly linked list
- `hash_table` — open-addressed hash table with integer values
- `binary_tree` — binary search tree support
- `string_utils` — safe string duplication, trimming, join, uppercase conversion
- `advanced_c_demo.c` — demo program using all modules

## Build

```bash
cd extensions/gemini-assistant/c-library
make
./advanced_c_demo
```

## Why this is stronger

- better structure than simple snippets
- reusable C modules
- safer memory handling patterns
- practical data structures for C projects
- easy to extend for custom applications
